# Frontend

Static, loadable documentation site for **Fusion Payroll**.

## Theme & UX
- Navy blue primary palette with light blue highlights.
- Typography with `Geomanist` (medium style when available) for headings and `Open Sans` light for body copy.
- Dedicated iconography across navigation and content sections.
- Responsive, user-friendly navigation (sticky sidebar on desktop, menu toggle on mobile).

## Run locally
From the repository root:

```bash
python3 -m http.server 4173 --directory frontend
```

Then open: `http://localhost:4173`.
